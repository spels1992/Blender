# Процедура готовый ресурс → Blender → Unity

1. **Поиск:** взять набор из `Catalog/ASSET_PACKS.md` либо пройти на сайт автора из `Catalog/SOURCE_PORTALS.md`.
2. **Право использования:** сверить `LICENSE_POLICY.md`, не перепаковывать сторонние ассеты в этот репозиторий; сохранить автора и условия.
3. **Скачать минимально необходимое:** выбрать бесплатную редакцию, предпочитать FBX/glTF/GLB, затем исходники .blend при наличии.
4. **Проверить Blender:** масштаб в метрах, ориентацию, нормали, UV, внешние пути к текстурам, mesh и armature, реальные размеры.
5. **Адаптировать:** привести шейдеры к будущему Unity URP/HDRP; убрать ненужную геометрию; при необходимости ретопология / LOD; создать коллайдер.
6. **Экспорт:** статичные объекты FBX или glTF, анимированные FBX; фиксировать настройки и исходную версию Blender.
7. **Импорт Unity:** проверять единицы, оси, материалы, skeleton avatar, анимации, prefabs и lightmap UV.
8. **Тест:** визуальная сцена + рабочая сцена + тест множественных экземпляров на целевой платформе.
9. **Фиксация:** карточка ассета, путь к оригиналу, лицензия, изменённые файлы *только если это разрешено условиями*, отчёт PASS/FAIL.

Рекомендуемые статусы: `SOURCE_VERIFIED` — страница и заявленные условия изучены; `INTEGRATION_TESTED` — воспроизводимо проверено в Unity; `LEGAL_REVIEW` — есть неоднозначность; `DEPRECATED` — источник устарел.

**Для ИИ:** у каждой задачи должен быть проверяемый результат. Одно нажатие «скачать» или создание .blend — не готовность; требуются отчёты G1-G5 из `ASSET_QA.md`.
