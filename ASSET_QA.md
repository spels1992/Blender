# Quality Gates — проверка найденных моделей

Готовый бесплатный ассет не обязательно технически пригоден для Unity. Все исходные игровые модели идут через G1–G5.

- **G0 Rights:** лицензия, автор, версия, бесплатная редакция, права на коммерческую игру, ограничения на перепубликацию.
- **G1 Geometry:** реальные размеры, pivot/origin, нормали, дырки/не-манифолдная геометрия, UV, применённые трансформации, материалы, текстурные пути.
- **G2 Rig/Animation:** skeleton, контрольные позы, skin weights, IK-контроллеры отдельно от деформационных костей, анимации/loop, совместимость retarget.
- **G3 Import:** FBX/GLTF → Unity; масштаб 1м, оси, mesh materials, alpha/roughness/smoothness, animator, prefab, colliders, LOD.
- **G4 Visual:** test-scene в Unity, скриншоты со всех ракурсов, силуэт, деформации, проверка эффекта реальных материалов.
- **G5 Performance:** triangles/vertices/draw calls, время кадра, память текстур и скелетов при ожидаемом числе экземпляров на реальной целевой платформе.

## Запрет на ложный PASS
- `SOURCE_VERIFIED` означает только найденную исходную страницу и изученные заявленные условия.
- `DOWNLOAD_CHECKED` — реально скачана доступная лицензированная версия, проверен состав файлов.
- `BLENDER_VALIDATED` — реальные проверки в Blender выполнены.
- `UNITY_TESTED` — реальные проверки импорта и сцены пройдены.
- `PRODUCTION_APPROVED` — прошли визуальные/лицензионные/производительные проверки.

Не изменять `UNITY_TESTED` без реального запуска Unity. Не фиксировать бесконечный лимит треугольников; сложность определяется габаритами на экране, платформой и целевой сценой.

## Перед использованием чужой модели
- [ ] Автор и URL оригинала записаны
- [ ] Дата лицензии и ограничения проверены
- [ ] FBX/GLB/BLEND формат реально скачан
- [ ] Отсутствуют подозрительные исполняемые файлы
- [ ] Текстуры и UV корректны
- [ ] Материал работает в выбранном Unity Render Pipeline
- [ ] Если есть риг — кости и анимации проверены
- [ ] Оптимизация проверена на целевой сцене
- [ ] Источник не републикуется в нарушение прав
