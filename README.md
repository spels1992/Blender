## Обязательные правила глобального поиска

**[GLOBAL_ASSET_SEARCH_POLICY.md](GLOBAL_ASSET_SEARCH_POLICY.md)** — **0 ₽ для коммерческой игры**, **минимум 2–3 действительно разных ассета каждого типа**, **МАКСИМУМ НЕ ОГРАНИЧЕН**. Искать **ВСЕ** форматы 3D/2.5D/2D, спрайты, модели, изометрию, текстуры и материалы (трава, кора, кирпич, шерсть, облака, земля, листья и любые другие), анимации, все стили, все жанры и все законные бесплатные источники.

Найдено 3 варианта? Продолжать поиск. Нет 2–3 вариантов? Оставить открытую задачу. Источники с похожими названиями или одним и тем же файлом не считать разными оригинальными моделями. Правило важно и для ежечасных задач.

**Учёт размера файлов:** `download_size_bytes` и размер на авторской странице сохранять при наличии; `UNKNOWN` если нет. [Аудит всех 639 URL и плановый объём](Catalog/DOWNLOAD_SIZE_ESTIMATE.md) — это пока не точные измерения архивов.

## Быстрый старт
1. Открыть [каталог игровых наборов](Catalog/ASSET_PACKS.md) и найти нужную категорию / ключевое слово.
2. Если требуется поиск по сотням тысяч моделей — открыть [список проверяемых библиотек](Catalog/SOURCE_PORTALS.md).
3. Проверить [матрицу лицензий](LICENSE_POLICY.md), **особенно различия между CC0 и лицензиями с запретом на перепубликацию ассетов**.
4. Перейти **по ссылке на конкретный оригинальный ресурс**, проверить актуальные условия, доступность бесплатной версии и формат.
5. Скачать оригинал непосредственно у автора и прогнать по [стандарту качества](ASSET_QA.md) перед интеграцией.
6. Если нет подходящего ресурса, создавать свой через Blender согласно [производственному процессу](PIPELINE.md).
