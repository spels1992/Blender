# Blender — библиотека готовых 3D-ресурсов для Unity

**Назначение:** находить и повторно использовать качественные бесплатные 3D-модели, персонажей, существ, оружие, анимации, технику, окружение, материалы и визуальные наборы **без складирования чужих файлов в GitHub**.

> Исследование и наполнение начаты 2026-10-08. Этот репозиторий — индекс внешних первоисточников, а не зеркало моделей. Пометка «изучено по сайту» НЕ означает, что архив скачан, прошёл проверку безопасности или протестирован в Unity.

## Быстрый старт
1. Открыть [каталог игровых наборов](Catalog/ASSET_PACKS.md) и найти нужную категорию / ключевое слово.
2. Если требуется поиск по сотням тысяч моделей — открыть [список проверяемых библиотек](Catalog/SOURCE_PORTALS.md).
3. Проверить [матрицу лицензий](LICENSE_POLICY.md), **особенно различия между CC0 и лицензиями с запретом на перепубликацию ассетов**.
4. Перейти **по ссылке на конкретный оригинальный ресурс**, проверить актуальные условия, доступность бесплатной версии и формат.
5. Скачать оригинал непосредственно у автора и прогнать по [стандарту качества](ASSET_QA.md) перед интеграцией.
6. Если нет подходящего ресурса, создавать свой через Blender согласно [производственному процессу](PIPELINE.md).

## Границы репозитория
- **Здесь:** готовые визуальные ассеты Blender/Unity, риги и анимации, материалы, природные и архитектурные наборы, источники моделей, правила импорта.
- **В [Unity](https://github.com/spels1992/Unity):** навигация, игровой ИИ, бои, физика, управление, генерация игрового мира и прочие движковые системы.
- **В [GameLibrary](https://github.com/spels1992/GameLibrary):** общие игровые библиотеки, наборы разработчика и инструменты.
