## Правило для ИИ-агента

Источник/лицензия → файл ZIP и карты → тайлинг/цветовые пространства → Blender проверка → Unity URP проверка → оптимизация для игры. Нельзя считать наличие страницы доказательством скачивания или полного набора PBR-карт. Для шерсти/плюша отделять PBR-поверхность от настоящего меха из 3D-волос.
