# MAT-054 — Fabric 02

**Материал:** Шерсть мех ткани кожа; группа `FABRIC`.

**Первоисточник:** [Fabric 02](https://www.cgbookcase.com/textures/fabric-02) (cgbookcase). **Лицензия по каталогу:** [CC0-1.0](https://www.cgbookcase.com/textures), бесплатное коммерческое использование; перепроверить условия на странице скачивания.

## Для игры
PBR-поверхность, не полноценная 3D-геометрия. Наличие Diffuse/BaseColor, NormalGL/NormalDX, Roughness, Metallic, AO и Height проверить перед использованием. Для шерсти и меха: плоский PBR-ворс не заменяет волосы/направленные 3D-пряди.

**Проверка:** только поисковая карточка; фактический архив **НЕ скачан**, бесшовность **НЕ проверена**, Blender/Unity URP **НЕ тестировались**. В GitHub храним ссылку и лицензию, не файлы авторов.
