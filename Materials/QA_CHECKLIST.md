# Контроль качества текстур и PBR-материалов — чек-лист

**Правило PASS:** нельзя ставить PASS только за страницу источника. В индексе материалы пока `SOURCE_PAGE_FOUND`.

## Этапы G0–G5

| Этап | Что нужно сделать | Статус до проверки |
|---|---|---|
| G0 — Источник | Точная URL страницы, автор, лицензия, отсутствие покупки/подписки, законность коммерции | SOURCE_PAGE_FOUND |
| G1 — Скачивание | Скачать **конкретный бесплатный архив**, сверить карты и формат, зафиксировать фактические имена и хеш локального файла | NOT_TESTED |
| G2 — PBR | Применить BaseColor, Normal, Roughness, Metallic/AO/Height по типу, проверить физический масштаб, швы на 4×4 тайлинге | NOT_TESTED |
| G3 — Blender | Сделать тест на нескольких мешах (шар/плоскость/куб); нормали и ноды без ошибок; записать рендер/скриншот и версию | NOT_TESTED |
| G4 — Unity URP | Назначить URP Lit, корректные texture types, normal Y, smoothness/metallic packing, проверить сцену и материалы | NOT_TESTED |
| G5 — Game-ready | Измерить FPS/VRAM в целевой сцене, исключить визуальные швы, подобрать LOD/texture size, оформить ссылку на исходник | NOT_TESTED |

## Обязательные поля доказательства
`asset_id`, `original_url`, `license_url`, `author`, `downloaded_on`, `local_archive_sha256`, `file_manifest`, `basecolor_name`, `normal_gl_name`, `normal_dx_name`, `roughness_name`, `metallic_name`, `ao_name`, `height_name`, `tiling_4x4_pass`, `unity_version`, `render_pipeline`, `gpu_or_test_device`, `fps_baseline`, `fps_with_material`, `qa_status`.

Если конкретной карты нет — указывать **ABSENT**, а не придумывать. Для неизвестного значения — **UNKNOWN**, отдельно от ABSENT.

## Ошибки, недопустимые в базе
- Писать, что текстура бесшовная, без проверки тайлинга.
- Записывать карты `normal_dx` и `normal_gl` как идентичные без просмотра.
- Считать roughness прямой заменой Unity smoothness (обычно требуется инверсия).
- Использовать 8K для сотен объектов по умолчанию.
- Считать PBR-плюш готовым 3D-мехом животного.
- Отмечать CC BY/CC BY-SA как CC0 либо забывать авторство.
- Считать источник с бесплатной миниатюрой и платным набором полноценным бесплатным ассетом.
- Загружать в публичный GitHub сторонние фото, карты или ZIP без разрешения.

## Отчёт
Для каждой проверенной текстуры формировать `Materials/QA/QA-MAT-XYZ.md` со статусами PASS/FAIL/NEEDS_REWORK **по факту**. Файл с готовым шаблоном без скриншота/импортной проверки не считать успешным испытанием. В [INDEX.json](INDEX.json) поля технических проверок до тех пор false.
