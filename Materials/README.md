## Правила использования агентом
1. Открыть [INDEX.json](INDEX.json), найти материал по нужной поверхности и эффекту (например, «влажный кирпич с мхом», «плюшевая шерсть»).
2. Проверить [страницу автора](https://polyhaven.com/textures) / [cgbookcase](https://www.cgbookcase.com/textures): скачать **бесплатный** PBR, убедиться в [CC0 Poly Haven](https://polyhaven.com/license) или CC0 cgbookcase и в реальных картах.
3. Выбрать нужные карты и разумное разрешение. Для прототипов обычно 1–2K; 4K/8K только с обоснованием качества и памяти.
4. Настроить материал по [инструкции Blender → Unity URP](PIPELINE.md), проверить швы/нормали, сохранить **реальный** отчёт по [QA](QA_CHECKLIST.md).
5. Только после выполненных проверок отмечать `UNITY_URP_TESTED=true`. Пока в индексе **0 реальных импортов**.

## Важное различие — шерсть
**Меховой PBR-материал** рисует цвет, микрорельеф и блеск на поверхности. Для пушистой кошки с реальным силуэтом шерсти нужны отдельные `hair cards`, particle/groom или geometry shell и совместимый шейдер. Коллекция `FUR_PLUSH` состоит из **поверхностных материалов** — это не готовые волосы, не риги и не 3D-перья.
