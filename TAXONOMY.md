# Открытый классификатор ВСЕХ игровых 3D / 2.5D / 2D-ресурсов

Это карта поиска по жанрам. **Категория не означает, что подходящий бесплатный набор уже найден**.

## Персонажи
- Люди: мужчина / женщина / ребёнок / пожилой / городской житель / рабочий / учёный / медик / военный / фермер / спортсмен
- Фэнтези: человек / эльф / тёмный эльф / орк / гоблин / гном / тролль / маг / паладин / разбойник / лучник / некромант
- Противники: скелет / зомби / призрак / вампир / демон / голем / робот / инопланетянин
- Боссы: дракон / виверна / гидра / гигант / механический босс
- Вариации: пол, возраст, одежда, причёски, морфы, комплекты брони

## Животные и существа
- Домашние: кошки, собаки, лошади, коровы, свиньи, овцы, птицы
- Дикие: волки, лисы, медведи, олени, рыбы, насекомые
- Динозавры и доисторические существа
- Морские, летающие, мифические и фантастические существа
- Отдельно: rigged, animated, idle/walk/run/fly/swim/attack/death

## Транспорт
- Городской: легковые, такси, автобус, грузовик, полиция, скорая, пожарная
- Спортивный: гоночные, внедорожники, мотоциклы, картинг
- Рельсовый: поезда, трамваи, вагоны
- Морской: парусники, корабли, лодки, подлодки
- Воздушный: самолёты, вертолёты, дирижабли, дроны
- Фантастический: космические корабли, мехи, танки

## Миры и окружение
- Природа: деревья, кусты, трава, цветы, скалы, грибы, пещеры, рельеф, водопады
- Средневековье: дома, замки, крепости, таверны, фермы, деревни, руины
- Город: жилые дома, офисы, фабрики, дороги, мосты, улицы, магазины
- Sci-Fi: базы, станции, лаборатории, ангары, космопорты
- Подземелья: коридоры, залы, двери, ловушки, сокровищницы
- Интерьеры: мебель, бытовая техника, кухонные, больничные, промышленные, общественные
- Для каждого: модули, LOD, коллизии, UV, единая сетка

## Предметы
- Оружие: мечи, топоры, луки, щиты, посохи, огнестрельное/фантастическое
- Броня, одежда, аксессуары, волосы, шлемы
- RPG: сундуки, монеты, ключи, зелья, ресурсы, инструменты
- Выживание: вода, еда, крафт, палатки, костры, контейнеры
- Городские предметы, вывески, мебель, промышленное оборудование
- Фэнтези-артефакты, научные приборы, электроника

## Анимации и визуализация
- Humanoid: idle, walk, run, jump, crouch, dodge, climb, swim, hit, death, interact
- Combat: one/two-handed, bow, gun, spellcast, block, reload
- Expression: blendshapes, phonemes, эмоции, лицевые риги
- Quadruped / wings / tentacles / robotics
- Motion capture libraries и ретаргетинг
- PBR-текстуры, HDRI, decals, skyboxes, shaders, foliage atlases

## Фильтры каталога
`category`, `subcategory`, `style` (realistic/stylized/lowpoly/voxel), `genre`, `format`, `rigged`, `animated`, `license`, `price`, `commercial`, `attribution`, `direct_url`, `source`, `verified_date`, `status`.

В остальных задачах (навигация, AI/NPC, физика, генерация поведения) искать в [spels1992/Unity](https://github.com/spels1992/Unity), а не дублировать здесь.

## Глобальный охват 2026-10-09 (переопределяет ограничение только 3D)

**Форматы представления:** `3D_MESH`, `3D_RIG`, `3D_ANIMATION`, `3D_VOXEL`, `POINT_CLOUD`, `CAD_SOURCE`, `VOLUMETRIC`, `2_5D_ISOMETRIC`, `2_5D_BILLBOARD`, `2_5D_MULTIDIRECTION_SPRITE`, `2D_SPRITE`, `2D_SPRITESHEET`, `2D_TILESET`, `2D_VECTOR`, `2D_PIXEL_ART`, `PBR_MATERIAL`, `2D_TEXTURE`, `3D_VOLUME_TEXTURE`, `PROCEDURAL_TEXTURE`, `TRIM_SHEET`, `FOLIAGE_ATLAS`, `SKYBOX`, `HDRI`, `DECAL`, `SHADER`, `VFX`, `UI_ART` и будущие полезные типы.

**Все стили:** realistic, photoreal, stylized, cartoon, anime-inspired, cel shaded, hand-painted, low-poly, high-poly, voxel, PS1/PS2/retro, pixel art, isometric, pre-rendered, clay, watercolor, vector, minimalist, fantasy, sci-fi. Добавление стилей не ограничено.

**Все жанры:** RPG, JRPG, action, survival, horror, sandbox, city-builder, farming, management, shooter, strategy/RTS, tactics, tower defense, platformer, race, sport, puzzles, adventure, educational, life-sim, metroidvania, roguelike, visual novel, games for PC/mobile/browser/VR/AR. Новые не исключать.

**Текстуры/поверхности:** дерево и кора любых пород, листья/хвоя, трава, мох, почва/грязь/песок/скалы, лед/снег/вода, облака/дым/туман, кирпич/плитка/бетон, металл/ржавчина/пластик/стекло, кожа/шерсть/мех/ткань, дороги, стены, полы/потолки/крыши, decals, PBR, trim sheets, alpha/foliage atlases, animated/projected/volumetric textures. Разделение на 2D/2.5D/3D обязательно сохранять.

**Варианты:** минимум 2–3 независимых ресурса каждого типа, без верхнего предела; продолжать искать после минимума. Ссылки на набор без доказательств наличия точного предмета не засчитывать.
