# C004-090 — Ель

Оригинал: [Poly Haven — Ель](https://polyhaven.com/a/fir_tree_01). **Лицензия:** CC0; бесплатно для коммерческого использования в игре.

Указанные на странице характеристики: 8M triangles; unsuitable as-is for mass vegetation in a game. Это реальные страницы 3D-ассетов, не ссылки на поисковую выдачу.

**Предупреждение об оптимизации:** даже CC0-ассет может быть слишком тяжёлым для Unity, особенно если повторяется сотнями экземпляров; для растительности и высокополигональных сканов нужны LOD, упрощение и измерения на целевой платформе. Не обещать пригодность без тестов.
