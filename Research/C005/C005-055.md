# C005-055: Банк — здание

**Задача:** найти минимум два разных бесплатных источника 3D-моделей, разрешённых для коммерческих игр. **Статус:** NO_EXACT_SOURCES; 0 точных совпадений по авторским страницам. **Blender/Unity:** NOT_TESTED.

## Найденные страницы
Пробел: конкретная бесплатная 3D-модель в проверенном пуле не подтверждена. Не считать портал, тег или 2D-картинку результатом.

## Условия
Проверить оригинальную страницу перед скачиванием, уточнить бесплатную редакцию, права для коммерческой игры, требования атрибуции CC-BY и ShareAlike. Модель должна иметь реальный mesh (.blend/.fbx/.glb/.obj). Запуск Blender и Unity, проверка материалов/LOD/коллизий/масштаба — отдельный обязательный этап. Чужие модели на GitHub не размещать.
