# Нулевая стоимость: обязательная политика библиотеки

**Дата:** 2026-10-08. Для всех категорий в этом репозитории действует правило: **только 100% бесплатные ассеты, пригодные для законного коммерческого использования в игре**.

## Разрешено
- CC0, когда источник обоснованно имеет права на опубликованный контент.
- CC BY, если ресурс без оплаты доступен для коммерции и мы можем соблюсти атрибуцию.
- CC BY-SA, если реально можно соблюсти attribution/share-alike; такие ресурсы помечаются `LEGAL_REVIEW`, не использовать автоматически без решения.
- Бесплатные ограниченные лицензии вроде Quaternius QAL, Fab Standard или Mixamo — лишь если соответствующая **конкретная** модель/анимация реально доступна бесплатно, коммерческое использование разрешено, а в игре запрещено извлекать/перепаковывать оригинал, если того требует договор.
- Бесплатная часть условно-бесплатных паков с коммерческим разрешением.

## Строго запрещено для отбора
- Обязательная покупка, платная модель или экспорт, платные исходники, платный аддон.
- Обязательная подписка, кредитная карта для автоматического списания, «7 дней бесплатно, затем платно», платная тарификация API/генерации.
- Лицензии только personal/non-commercial/editorial, сомнительные репаки, ассеты чужих франшиз без права коммерческой эксплуатации.
- Выдавать на странице поиска модели только со статусом "free" без проверки разрешения на коммерческое использование.
- Копировать чужие ZIP, модели и текстуры в публичный GitHub без разрешения автора.

## Обязательные поля новой модели
`source_url`, `author`, `free_download_url`, `license`, `license_url`, `commercial_allowed`, `redistribution_restrictions`, `found_date`, `exact_item_evidence`, `blender_test_status`, `unity_test_status`.

**Различать уровни:**
1. `CANDIDATE_ONLY`: известен подходящий пакет, но неизвестно содержит ли он нужный предмет.
2. `EXACT_PAGE_FOUND`: есть отдельная страница модели либо набор, где предмет перечислен явно; файлы не скачаны.
3. `DOWNLOAD_CHECKED`: архив реально скачан и файл существует.
4. `BLENDER_VALIDATED`: вручную или скриптом проведена реальная проверка модели Blender.
5. `UNITY_TESTED`: импортировали и испытали в Unity.
6. `PRODUCTION_APPROVED`: лицензии, пригодность и производительность окончательно приняты.

**Три ссылки на тематические коллекции не равны трём экземплярам целевой модели!** Если точных моделей меньше двух, писать об этом прямо, сохранять GAP и возвращаться к нему.

## Дополнение 2026-10-09 — объём поиска и диапазон графики

**Основное актуальное правило:** [GLOBAL_ASSET_SEARCH_POLICY.md](GLOBAL_ASSET_SEARCH_POLICY.md) — имеет приоритет над более узкими историческими формулировками.

- Искать **все** 3D, 2.5D, 2D и дополнительные полезные графические форматы; не ограничиваться только mesh, моделями, предметами или персонажами. Включать сцены, анимации, sprites, tiles, skyboxes, HDRI, декали, шейдеры, облака, листья, траву, кору, кирпич, почву, шерсть и другие материалы.
- **Минимум 2–3 независимых различных модели/ресурса каждого типа, максимум НЕ ограничен.** Даже найдя 3, продолжать расширять каталог по всем источникам, стилям, жанрам. Для 2D/2.5D/3D искать вариации независимо, если они существуют.
- Изучать **любые законные бесплатные источники** с разрешённой коммерцией, список порталов — не фильтр источников.
- В карточку добавлять известный реальный размер скачивания (`download_size_bytes`), источник измерения и данные по форматам/разрешениям. Неизвестный размер = `null`, а не выдуманный ноль или оценка как точное значение.
