# 2D и 2.5D: бесплатные игровые ресурсы

**Добавлено: 2026-10-09.** 42 оригинальные страницы CC0 для изометрии, пиксель-арта, облаков, травы, городских окружений и RPG. [Машиночитаемый индекс](INDEX.json).

**2.5D в нашем каталоге означает изометрические 2D-спрайты**, не полигональные 3D-модели. Реальная совместимость в Unity/Blender пока не тестировалась.

Цена 0 ₽, коммерческое использование разрешено заявленной CC0 лицензией. ZIP и PNG не скачивали. Количество файлов/спрайтов — не мегабайты, размеры записаны только если указаны автором. [Оценка объёма всех ресурсов](../DOWNLOAD_SIZE_ESTIMATE.md).

## Правило дальнейшего поиска

Минимум 2–3 **независимых** источника на тип; **максимума нет**. Все стили и жанры, все бесплатные законные площадки. Искать 2D, 2.5D, 3D, vector, pixel, voxel, процедурные материалы, лес, растения, облака, карты, анимации, декали, HDRI. Изометрический набор 2D не засчитывать за true 3D mesh. См. [GLOBAL_ASSET_SEARCH_POLICY.md](../../GLOBAL_ASSET_SEARCH_POLICY.md).
