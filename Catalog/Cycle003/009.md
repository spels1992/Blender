**Категория:** Офис и школа. **Дата:** 2026-10-08. **Бюджет:** 0 ₽, только бесплатное коммерческое использование. **Статус поиска:** 2+ EXACT_PAGES. **Статус теста Blender/Unity:** NOT_TESTED.

## Проверенные первоисточники / кандидаты
1. [Old Bookshelf with Books](https://opengameart.org/content/old-bookshelf-with-books) — лицензия **CC0**, `EXACT_MODEL`, бесплатно по публикации.
2. [3D Interior Home Assets — shelf with books](https://opengameart.org/content/3d-interior-home-assets) — лицензия **CC0**, `EXACT_PACK_CONTENT`, бесплатно по публикации.
3. [LowPoly Bookshelf (books not included)](https://opengameart.org/content/lowpoly-bookshelf) — лицензия **CC0**, `RELATED_NOT_EXACT`, бесплатно по публикации.

## Следующие действия
1. Искать "Книжная полка с книгами" на [OpenGameArt](https://opengameart.org/) и [Kenney](https://kenney.nl/assets) с фильтром именно **3D** и коммерчески разрешённой лицензии.
2. Довести до **2–3 независимо созданных точных моделей**. Не считать теги, похожие объекты или перепаковки независимыми.
3. Проверить исходный ZIP/.blend/.fbx, реальный бесплатный download и license notice.
4. Прогнать Blender → Unity тест, зафиксировать качество и производительность. Пока не ставить PASS.
