# Источники для бесплатных игровых 2D/2.5D/3D-ресурсов и текстур

**С 2026-10-09 [глобальная политика](../GLOBAL_ASSET_SEARCH_POLICY.md) имеет приоритет:** это стартовые площадки, а НЕ закрытый белый список! Искать на **любых** сайтах, у любых авторов, включая 3D / 2.5D / 2D, спрайты, тайлы, изометрию, карты, UI, все стили/жанры и любые текстуры (кора, трава, кирпич, облака, листья, шерсть, грязь и др.). На каждый тип 2–3 разных варианта минимум, максимума нет; не прекращать поиск после 3. Только законный бесплатный коммерческий контент.

Проверены по публичным страницам 2026-10-08. **Портал — не лицензия на любой его файл**. Сохранять карточку конкретного объекта после выбора.

## Приоритет поиска
1. **CC0 и действительно бесплатная редакция** — Kenney, Poly Haven, ambientCG, KayKit.
2. **Бесплатно использовать, нельзя перевыкладывать** — Quaternius по нынешней QAL, Fab, Mixamo, Royalty Free.
3. **Смешанные лицензии/качество** — Sketchfab, Poly Pizza, CGTrader, itch.io, OpenGameArt, Blendkit.

**Не включены как свободные ресурсы без дополнительных проверок:** краденые ассеты, репаки из Asset Store, игры с вытащенными модельными файлами, чужие персонажи известных франшиз без разрешения, файлы без лицензии.

## ВАЖНО — список НЕ ограничивает поиск (2026-10-09)

Все сайты в таблице выше — **только известные примеры, а НЕ обязательный закрытый перечень**. Ищи **в любых** интернет-каталогах, репозиториях GitHub/GitLab, сайтах авторов, сообществах, архивах, порталах 2D/2.5D/3D/вокселей/текстур/спрайтов/VFX, если для **конкретного** ассета юридически подтверждены бесплатность и коммерческие права. Не останавливайся на Kenney, Poly Haven, OpenGameArt и других привычных сайтах.

Обязательная задача — **непрерывное расширение**: минимум **2–3 разных варианта на каждую категорию**, а сверху искать **столько, сколько удастся**, без предельного количества. Искать **любые стили и игровые жанры**, независимо от текущей игры.
