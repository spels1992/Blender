## Условия и статус
- Пакеты — кандидаты, а не подтверждённые поштучные модели. Чтобы присвоить `EXACT_MATCH`, найти точный объект внутри бесплатного архива.
- Сравнить два-три разных варианта; не считать 3 ссылки доказательством наличия 3 моделей.
- **Покупка не требуется.** Kenney: CC0; Quaternius: QAL без оплаты для коммерческой игры и запрет отдельной перепродажи; KayKit: только бесплатная редакция, не платные source файлы.
- Blender/Unity тесты ещё не проведены: `UNITY_NOT_TESTED`. Чужие архивы не зеркалируются на GitHub.
