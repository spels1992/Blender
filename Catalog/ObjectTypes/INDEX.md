# Индекс 100 типов 3D-объектов для игр — ТОЛЬКО БЕСПЛАТНО

**Завершено: 100/100 карточек исследовательских задач (цикл 002); сохранены последовательно отдельными коммитами.**

- **167** находок на **150 уникальных** страницах конкретных CC0-моделей и наборов с явно указанным содержимым.
- **88/100** типов представлены подтверждёнными страницами; **12/100** пока требуют поиска более точной бесплатной модели.
- **300 привязок** к тематическим бесплатным наборам (по три кандидата для каждого типа), это **не** 300 отдельных моделей.
- Исходные файлы пока **не скачаны**, интеграция в Unity/Blender **не испытывалась**, FPS **не измерен**.

Бюджет: **0 ₽**. Бесплатное коммерческое использование обязательно. Источники: CC0, бесплатные наборы Quaternius QAL (без права отдельно распространять исходные ассеты) и бесплатные CC0-версии KayKit. Платные исходники, обязательные подписки, магазины и пробные периоды не используем. [Лицензии](../../LICENSE_POLICY.md).
