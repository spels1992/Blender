# Blender — обязательные правила локального хранения

## Любые подключённые плагины и скиллы ChatGPT

- **Разрешено свободно использовать любые плагины (MCP/коннекторы/приложения) и отдельные скиллы, которые реально доступны и подключены к ChatGPT пользователя**, если они полезны для текущей задачи. Это касается как существующих, так и новых инструментов, которые будут подключены в будущем.
- Перечни конкретных инструментов в этом репозитории — **не исчерпывающие списки и не ограничение**. Выбирать и сочетать подходящие плагины и скиллы по задаче, а перед выполнением проверять их фактическую доступность и возможности. Если предпочтительный инструмент недоступен, искать доступную альтернативу.
- Для действий на компьютере, в GitHub, Blender, Unity, ComfyUI и других системах использовать соответствующие подключённые инструменты по назначению. Соблюдать права доступа, правила безопасности и необходимость подтверждения пользователя для отдельных операций. Не заявлять о выполнении действия без проверки результата.
- Не устанавливать платные программы, подписки и сторонние платные сервисы без отдельного согласования; по возможности использовать уже подключённые и бесплатные возможности.


## Свободное использование подключённых плагинов и скиллов ChatGPT

**Разрешено использовать любые плагины, MCP-инструменты и скиллы, которые пользователь подключил или установил в ChatGPT**, включая добавленные позднее, если они помогают решить текущую задачу. Это общее разрешение действует для Blender, Unity и «Фермы»: перечисления инструментов в документации — примеры и приоритеты, **не закрытый список**. Можно сочетать инструменты и скиллы разных плагинов, подбирать оптимальную комбинацию и привлекать доступные средства анализа, разработки, тестирования, моделирования, анимации, автоматизации и GitHub.

Перед использованием проверять, что конкретный инструмент действительно доступен и подходит для задачи; не утверждать о выполнении действий без подтверждённого результата. Сохранять существующие правила проектов и приоритетные MCP при работе с локальным ПК. Дополнительные платные сервисы/подписки и подключение новых аккаунтов требуют отдельного согласия пользователя; по умолчанию выбирать бесплатные варианты. Не публиковать секреты и учётные данные, соблюдать лицензии, согласовывать необратимые или рискованные операции.

## Обязательные плагины и восстановление

- **Windows MCP и WinApp MCP** — два основных инструмента управления Windows: командный/системный и оконный/UI соответственно.
- **Blender MCP** — работа непосредственно в Blender; при недоступности восстанавливать аддон, GUI, сервер и туннель **через Windows MCP или WinApp MCP**. Проверять живой командой Blender MCP. С резервным клиентом Blender на ПК может запускаться автоматически.
- **Unity MCP** (AnkleBreaker Unity MCP Server) — работа в Unity Editor; при недоступности восстанавливать Unity Hub, Editor, лицензирование, сервер и туннель **через Windows MCP или WinApp MCP**, затем проверять `unity_editor_ping`.
- **Desktop Commander / Remote Desktop Commander допускается ИСКЛЮЧИТЕЛЬНО для восстановления Windows MCP и WinApp MCP**. Никакой разработки, моделирования, восстановления Blender/Unity MCP напрямую, GitHub или работы с файлами через него.
- Общий стандарт **ComfyUI → Stable Fast 3D (при подтверждённой генерации GLB) → Blender MCP → Unity MCP**, единые D: пути и сохранения — [WORKFLOW_AND_PATHS.md](WORKFLOW_AND_PATHS.md). При конфликте старых правил руководствоваться им и [LOCAL_ASSET_PATHS.md](LOCAL_ASSET_PATHS.md).


## Единые локальные папки AI-заготовок (обязательно)

- **ComfyUI:** `D:\Blender\Comfy\3D заготовки` — промежуточные изображения, текстуры и заготовки ComfyUI.
- **Stable Fast 3D:** `D:\Blender\Stable 3D\3D заготовки` — GLB, черновые 3D-модели, рендеры, QA и промежуточные результаты SF3D.
- Каждый персонаж/объект получает свою подписанную подпапку. Финальные утверждённые модели и .blend хранить отдельно в `D:\Blender\Models\<имя модели>\`.
- Сами программы установлены в `D:\Program Files\`; не смешивать каталоги результатов с библиотеками, весами и кэшами.
- Подробности: **[LOCAL_ASSET_PATHS.md](LOCAL_ASSET_PATHS.md)**. Использовать это правило перед каждым AI→Blender→Unity заданием. Токены и большие черновики на GitHub не загружать.


## Канонический корень
Единственный корень Blender-работ: `D:\Blender\`.

## Верхний уровень
- `D:\Blender\Models\` — все именованные модели/персонажи/объекты.
- `D:\Blender\Tools\` — общие Blender-скрипты, аддоны и инструменты, не принадлежащие одной модели.
- `D:\Blender\Shared\` — общие материалы/референсы/ресурсы, реально используемые несколькими моделями.
- `D:\Blender\Archives\` — сознательно архивированные материалы; не рабочая зона.

## Модели
Каждая самостоятельная модель обязана иметь отдельную подписанную папку:
`D:\Blender\Models\<ModelName>\`.
Например: `D:\Blender\Models\Koshka-Kartoshka\`.
Нельзя складывать разные модели в одну безымянную рабочую папку.

Внутри папки конкретной модели разрешено создавать сколько угодно осмысленных подпапок. Рекомендуемые при необходимости:
- `Source\` — .blend и основные исходники;
- `Textures\` — текстуры;
- `Materials\` — материалы;
- `References\` — референсы;
- `Scripts\` — код обработки/генерации, относящийся только к этой модели;
- `Exports\` — FBX/GLB/OBJ и прочие экспорты;
- `Renders\` — рендеры/превью;
- `Versions\` — осознанно сохранённые промежуточные версии.

## Правила
- Имя папки должно однозначно описывать модель.
- Общий код обработки нескольких моделей хранить в `D:\Blender\Tools\`, код одной модели — внутри её `Scripts\`.
- Не создавать новые модели/рендеры/экспорты непосредственно в `D:\Blender\` или на D:.
- Не плодить копии вида final-final-2 без необходимости; использовать понятные версии внутри папки модели.
- Перед перемещением legacy-модели проверить связанные текстуры, внешние пути, Unity references и Git-состояние.
- Старые файлы не удалять, пока новая каноническая копия не проверена.

## Генерация новых ассетов через локальный ИИ (2026-10-12)

**Для каждой подходящей новой модели сначала проверять** бесплатный локальный ComfyUI (референсы/изображения/текстуры при наличии установленной модели) и Stable Fast 3D (image-to-3D, после подтверждённого запуска). Установки: `D:\Program Files\ComfyUI\` и `D:\Program Files\StableFast3D\`. Инструкция, точные исполняемые пути, лицензии и ограничения: [docs/LOCAL_AI_3D_PIPELINE.md](docs/LOCAL_AI_3D_PIPELINE.md). Использовать как вспомогательные производственные инструменты, **не заменяя Blender**: обязательны топология/ретопология, пропорции, PBR, UV, оптимизация, риг/анимации и экспорт в Unity. SF3D не гарантирует анатомию/шерсть/чистую геометрию и пока не доказан реальной генерацией GLB; если его качество или запуск не подходит — моделировать вручную. Никаких платных API, секретов в GitHub и непроверенных лицензий; соблюдать каталоги `D:\Blender\`.
