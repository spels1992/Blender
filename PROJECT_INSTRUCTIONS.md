# Blender — обязательные правила локального хранения

## Единые локальные папки AI-заготовок (обязательно)

- **ComfyUI:** `D:\Blender\Comfy\3D заготовки` — промежуточные изображения, текстуры и заготовки ComfyUI.
- **Stable Fast 3D:** `D:\Blender\Stable 3D\3D заготовки` — GLB, черновые 3D-модели, рендеры, QA и промежуточные результаты SF3D.
- Каждый персонаж/объект получает свою подписанную подпапку. Финальные утверждённые модели и .blend хранить отдельно в `D:\Blender\Models\<имя модели>\`.
- Сами программы установлены в `D:\Program Files\`; не смешивать каталоги результатов с библиотеками, весами и кэшами.
- Подробности: **[LOCAL_ASSET_PATHS.md](LOCAL_ASSET_PATHS.md)**. Использовать это правило перед каждым AI→Blender→Unity заданием. Токены и большие черновики на GitHub не загружать.


## Канонический корень
Единственный корень Blender-работ: `D:\Blender\`.

## Верхний уровень
- `D:\Blender\Models\` — все именованные модели/персонажи/объекты.
- `D:\Blender\Tools\` — общие Blender-скрипты, аддоны и инструменты, не принадлежащие одной модели.
- `D:\Blender\Shared\` — общие материалы/референсы/ресурсы, реально используемые несколькими моделями.
- `D:\Blender\Archives\` — сознательно архивированные материалы; не рабочая зона.

## Модели
Каждая самостоятельная модель обязана иметь отдельную подписанную папку:
`D:\Blender\Models\<ModelName>\`.
Например: `D:\Blender\Models\Koshka-Kartoshka\`.
Нельзя складывать разные модели в одну безымянную рабочую папку.

Внутри папки конкретной модели разрешено создавать сколько угодно осмысленных подпапок. Рекомендуемые при необходимости:
- `Source\` — .blend и основные исходники;
- `Textures\` — текстуры;
- `Materials\` — материалы;
- `References\` — референсы;
- `Scripts\` — код обработки/генерации, относящийся только к этой модели;
- `Exports\` — FBX/GLB/OBJ и прочие экспорты;
- `Renders\` — рендеры/превью;
- `Versions\` — осознанно сохранённые промежуточные версии.

## Правила
- Имя папки должно однозначно описывать модель.
- Общий код обработки нескольких моделей хранить в `D:\Blender\Tools\`, код одной модели — внутри её `Scripts\`.
- Не создавать новые модели/рендеры/экспорты непосредственно в `D:\Blender\` или на D:.
- Не плодить копии вида final-final-2 без необходимости; использовать понятные версии внутри папки модели.
- Перед перемещением legacy-модели проверить связанные текстуры, внешние пути, Unity references и Git-состояние.
- Старые файлы не удалять, пока новая каноническая копия не проверена.

## Генерация новых ассетов через локальный ИИ (2026-10-12)

**Для каждой подходящей новой модели сначала проверять** бесплатный локальный ComfyUI (референсы/изображения/текстуры при наличии установленной модели) и Stable Fast 3D (image-to-3D, после подтверждённого запуска). Установки: `D:\Program Files\ComfyUI\` и `D:\Program Files\StableFast3D\`. Инструкция, точные исполняемые пути, лицензии и ограничения: [docs/LOCAL_AI_3D_PIPELINE.md](docs/LOCAL_AI_3D_PIPELINE.md). Использовать как вспомогательные производственные инструменты, **не заменяя Blender**: обязательны топология/ретопология, пропорции, PBR, UV, оптимизация, риг/анимации и экспорт в Unity. SF3D не гарантирует анатомию/шерсть/чистую геометрию и пока не доказан реальной генерацией GLB; если его качество или запуск не подходит — моделировать вручную. Никаких платных API, секретов в GitHub и непроверенных лицензий; соблюдать каталоги `D:\Blender\`.
